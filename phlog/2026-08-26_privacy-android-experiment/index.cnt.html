During the last couple of months I've been thinking about switching from my iPhone back to Android, after making the switch 3 year ago, but this time take the opportunity to force myself to try to have a more privacy-focused experience. This post is basically a brain dump of the first couple of days trying to setup a privacy-focused Android phone and trying to live with it alongside my iPhone.

The device I chose for this experiment was my Fairphone 5, a device I sadly didn't use for a long time due to a series of issues with the early unit I had, leading me eventually to switch to the iPhone I currently use.

Unlocking the bootloader and installing /e/OS

I chose to use /e/OS as the privacy-focused custom ROM for this experiment. Deciding between it and LineageOS wasn't easy, there's a lot of fanboyism only for both ROMs, making getting credible information about each a bit difficult, but in the end I decided that /e/OS with their own stock applications removed manually later would provide me the best privacy out-of-the-box.

The first step towards installing this custom ROM involved removing all my accounts and screen locks from the stock ROM and unlocking the Fairphone's bootloader. I thought this was going to be easy, since I had done it many times in the past, during the Gingerbread and Lollipop eras, but apparently this process is now a lot more involved.

Following the official bootloader unlocking guide from Fairphone was straightforward. The only issue I had was that my device wasn't recognized by Windows when it was in bootloader mode. To fix this I had to use weird workaround using Windows Update to ensure that I had the correct drivers. I couldn't find these drivers anywhere on the internet for download without using Windows Update.

After installing the drivers, I was able to successfully unlock my bootloader and procceed with the installation of /e/OS using the command-line method, which I must admit was very easy compared to what I was used to when it comes to custom ROMs in the past.

Rooting the device

Since my goal is to properly own my own device for the first time in a decade, I decided that I was going to root it on principle.

According to the /e/OS support guide on rooting, you can't root an official build using adb, thus forcing me to use Magisk, a tool I've never used before, since the last time I had root on one of my devices this was done using recovery mode and the SuperSU application.

The installation of Magisk is quite a roundtrip between the computer and your device, having to patch the boot image on the device and having to transfer it back for installation, but overall went without any issues. Now I can finally own my smartphone and do whatever I want with it, after all it's a computer like any other.

Installing applications

As the focus of this experiment is to be privacy-focused, I will try to stay away from the Play Store as much as possible, thus the majority of my applications are going to be installed using F-Droid, where the majority of open source applications for Android are hosted, or Obtainium, whenever I encounter an application that's only available via GitHub.

Removing bloatware

Although /e/OS is pretty light and doesn't come with much bloat, it still has a couple of applications that are packed in the default install that I won't ever use and are, in my opinion, bloatware, specially the ones that are linked to their Murena Cloud offering.

To remove these applications I used Shizuku, an application that provides a common root API interface, together with Canta, an application that allows the user to uninstall any application on the operating system, even the ones that would lead to a bricked system.

The stock applications that I have removed were:

  • /e/ Drive (foundation.e.drive)
  • Backup (foundation.e.backup)
  • Browser (foundation.e.browser)
  • Calendar (foundation.e.calendar)
  • Camera (foundation.e.camera)
  • Mail (foundation.e.mail)
  • Maps (com.generalmagic.magicearth)
  • Message (foundation.e.message)
  • Notes (foundation.e.notes)
  • MJ PDF (foundation.e.pdfviewer)
  • Tasks (foundation.e.tasks)
  • Web Calendar Manager (foundation.e.webcalendarmanager)

Conclusion

I don't know if I'll be able to use only my Fairphone as my only smartphone, but I'll give it the best shot possible. Hopefully in a couple of months I'll be sharing my positive experience...
